# Match data goes here (never committed)

Unpack the competition's tactical data into this folder, keeping the original file names:

```
data/tactical/BAR-ATH_tactical_atd.txt
data/tactical/BAR-ATH_tactical_atd.xml
data/tactical/BAR-ATH_tactical_smart_tagging.xml
```

The video, the homography and the broadcast files are not used. To keep the data elsewhere, set
`MTAH_DATA_DIR` to the folder that holds `tactical/`. Everything in `data/` except this file is
ignored by git: the match data is licensed for the competition only.
